# Shine Music 功能清单

> 更新日期：2026-10-22
> 产品定位：私人音乐库 + 邀请制小型共享曲库（个位数~十位数用户），不接第三方音乐平台。
> 部署形态：后端跑在家庭主机（Kestrel 0.0.0.0:5180），公网经 Tailscale Funnel（`https://node.tail78b610.ts.net`）转发；APK 经 HBuilderX 云打包、GitHub Release 分发。
> 前端唯一源码工程：`ShineMusicApp/`（uni-app + Vue3），H5 与 App 共用。

### 1.2 首页与导航

- 自绘 5 位 tabbar：4 个内容 tab（选中态胶囊底色）+ 中间凸起圆形按钮（带未读角标）
- QuickPanel 底部宫格（六宫格）：消息 / 播放历史 / 收藏 / 关注 / 上传 / 主题；未登录直接跳登录页
- 今日灵感卡：按时段匹配灵感曲目，英文流派标签映射为中文 mood 标签
- 最近加入曲目、全库关键词搜索（歌曲/艺人/专辑）

### 1.3 播放器（全局组件 PlayerBar）

- 迷你播放条：常驻底部、点击展开全屏（132rpx 避让首页凸起按钮）、迷你频谱、下一首快捷键
- 全屏播放页：黑胶唱片旋转、封面主色动态背景、律动频谱条
- 歌词：LRC 逐行高亮自动滚动、点击行跳转进度、纯文本歌词降级、沉浸歌词模式（大字居中铺满）
- 手势：封面左右滑切歌、下滑收起、双击收藏、单击切换歌词模式
- 播放控制：播放模式三态（顺序/随机/单曲循环）、上一首/播放暂停/下一首、进度条触摸 seek、播完自动连播
- 播放队列：底部抽屉列出当前队列、点击条目切歌（入口在「评论」药丸行）
- 快捷操作药丸行：评论 / 播放列表 / 加歌单 / 音效（仅 H5）/ 不感兴趣
- 音效 EQ：八预设（原声/流行/摇滚/古典/爵士/人声/低音增强/高音增强，Web Audio，仅 H5）
- 横屏双栏布局：左栏封面+控制，右栏歌词毛玻璃常驻；队列/音效改右侧滑入面板

### 1.4 社交与个人

- 曲目评论、评论点赞
- 关注 / 粉丝列表
- 消息中心：未读角标、全部已读、删除；未登录不发未读数请求
- 收藏（幂等）、自建歌单（创建/改名/加歌/移出/删除）、播放历史
- 歌曲需求：提交、投票（不可撤销）、撤回、处理时间线
- 上传本地音频（登录用户；转码与歌词匹配完成后自动入库）
- 个人资料编辑、头像

### 1.5 主题与多语言

- 多套预设主题：CSS 令牌即时换肤，全站生效
- 自定义图片壁纸主题（H5 完整流程）：选图 → 裁剪编辑器（拖动/双指捏合/滚轮缩放，固定屏幕比例取景框）→ 最长边 2560px WebP 导出 → 取色 → 整页生效 → 上传后端；多端同步以后端 `enabled` 为唯一事实源
- 多语言 i18n：简体中文 / English / 日本語
  - 切换入口：ProfileDrawer「语言」行（内嵌展开）+ 登录页右上角行内切换
  - 持久化存储 + 无偏好时跟随系统语言
  - 当前翻译覆盖：播放器部分文案（音效、正在播放、暂无歌词等）；其余页面文案仍为硬编码中文，逐步迁移

### 1.6 认证与管理端（同工程按角色显隐）

- 登录（回车提交、错误友好提示）、邀请注册（邮件链接 / CDK 注册码双通道）
- 管理员功能：
  - 曲库导入审核：批量上传（H5 多选/App 选择）、逐文件解析状态、元数据修正、歌词三入口（自动提取/歌词文件上传/手动粘贴）、关联点歌需求、发布
  - 曲目维护：已发布曲目元数据修正、缺失信息/重复项筛选
  - 歌单管理：编辑精选专题
  - 需求管理：状态流转、拒绝原因、重新开启
  - 邀请管理：邮件邀请、CDK 生成、重发、撤销
- 服务器地址：ProfileDrawer 内查看/修改后端地址（保存即生效，App 端失联自救入口）

### 1.7 基础能力

- 免登录匿名浏览与播放已发布曲目
- http 层统一封装：401 自动刷新令牌并重试一次、错误码映射中文文案
- 契约类型同步：`yarn check:contracts`（后端 Contracts → 前端 types）
- App 端 lucide 图标 CSS-mask shim（`yarn gen:icons` 生成，vite alias 替换原库）

## 二、后端功能清单（ShineMusic.Api，.NET 10 Minimal API）

基础路径 `/api/v1`；错误统一返回稳定错误码与可读消息；管理写操作写审计记录。

| 端点组 | 能力 | 鉴权 |
|---|---|---|
| System | `/health` 健康检查；`/system/capabilities` 功能开关、格式白名单、上传限制 | 匿名 |
| Catalog | 曲目/专辑/艺人/风格列表与详情（筛选分页）、`/music/home` 首页聚合、关键词搜索、`/tracks/{id}/stream` HTTP Range 流播放（206） | 匿名 |
| Artwork | 封面读取（匿名）；封面抓取（iTunes）与上传（管理员） | 混合 |
| Auth | 邀请令牌验证、注册（仅邀请制）、登录、刷新、登出、`/me` | 混合 |
| Invitations | 管理员创建邀请（邮件 + CDK 注册码双通道，注册码仅存哈希、明文展示一次）、列表、重发、撤销 | 管理员 |
| SongRequests | 需求池浏览（匿名）、提交/投票/撤回/时间线（登录）、投票不可撤销、重复需求检测 | 混合 |
| 需求管理 | 状态机流转（open/planned/in_progress/fulfilled/declined/withdrawn；declined 与 withdrawn 可对称重开为 open）、拒绝原因必填、fulfilled 关联曲目校验、审计 + 站内信 | 管理员 |
| Notifications | 站内信列表、未读数、单条/全部已读、删除 | 登录 |
| Comments | 曲目评论、评论点赞 | 读取匿名 / 写入登录 |
| Follow | 关注、粉丝列表 | 登录 |
| UserLibrary | 收藏（幂等）、歌单 CRUD、加歌/移歌 | 登录 |
| UserUploads | 登录用户上传本地音频，进入用户库 | 登录 |
| Theme | 用户主题偏好读写；壁纸上传（≤8MB，JPEG/PNG/WebP 魔数校验）与读取（登录鉴权） | 登录 |
| Profile | 个人资料、头像 | 登录 |
| Lyrics | LRCLIB 歌词匹配（网络重试/结果缓存/定时补全）、曲目歌词读取 | 混合 |
| Listening | 播放行为上报（started/progress/completed/skipped） | 登录 |
| Recommendation | 每日推荐、相似曲目 | 混合 |
| LibraryImport | 管理员隔离导入：multipart 批量上传 → 流式写入隔离区 → 格式魔数校验（MP3/FLAC/WAV/AAC/M4A/Ogg/WMA/AIFF/APE/MPC/WV/DSF）→ TagLib# 元数据解析 → AAC 192kbps 转码 → iTunes 元数据补全 → 歌词解析/翻译 → 需求关联与发布校验（标题/艺人匹配，可 forceFulfill 覆盖并审计）→ 发布 → 隔离文件清理 | 管理员 |
| CatalogManagement | 曲目/专辑/艺人元数据修正、精选专题维护（PUT 全量重建曲目顺序） | 管理员 |
| Storage | 存储治理对账（排除 themes/ 目录） | 管理员 |

### 基础设施

- JWT 双令牌：访问令牌 + 刷新令牌（仅存 SHA256 哈希）
- FeatureGate 功能开关：关闭的功能路由统一返回 404
- 管理员操作审计表、CorrelationContext 链路追踪日志、文件日志 Provider
- SqlSugar CodeFirst 启动时幂等建表（36 张实体表，涵盖曲库 → 身份/邀请 → 歌单/需求 → 导入 → 审计 → 歌词 → 听歌行为 → 用户上传 → 站内信 → iTunes 元数据 → CDK → 社交 → 评论点赞 → 主题）
- 生产部署：Kestrel `0.0.0.0:5180`（appsettings.Production.json）、Tailscale Funnel 443 → 127.0.0.1:5180、CORS 白名单（含 App 端 `null` origin 预留）

## 三、App 功能清单（APK，HBuilderX 云打包）

### 3.1 与 H5 同源

- 同一 ShineMusicApp 源码全量打包：24 页面、完整播放器、社交、主题、管理员功能
- 横竖屏双方向渲染，PlayerBar 横屏双栏形态

### 3.2 App 专属机制

- 启动竞态兜底（`app-boot-fix.ts`）：`__registerApp` 丢失导致白屏时的自动救援（2.5s 检测 → 手动注册 → 补发 onWebviewReady → reLaunch 兜底）
- lucide 图标 shim：原生 SVG 在 uni-app v3 渲染桥不生效，构建时 vite alias 替换为 CSS mask 绘制的 shim 组件（`yarn gen:icons`，当前 64 图标）
- 服务器地址：APK 内置 `config/hosts.json` 的 `server.appApiOrigin`（`yarn build:app` 注入）；ProfileDrawer「服务器地址」运行时覆盖自救
- manifest：Android 明文流量许可（`usesCleartextTraffic`）、uniStatistics 显式关闭

### 3.3 平台差异（App vs H5）

| 功能 | H5 | App |
|---|---|---|
| 音效 EQ（Web Audio） | 可用 | 不可用（音效按钮自动隐藏） |
| 壁纸裁剪编辑器 | 可用（Pointer Events） | 不可用（选图走降级流程） |
| i18n / 主题 / 播放 / 社交 | ✓ | ✓ |
| 服务器地址构建期注入 | 走 vite mode | `hosts.json` → `__SM_API_BASE__` |

### 3.4 打包与分发

- 编译器：@dcloudio 全家桶精确锁 `3.0.0-alpha-5020520260821001`（与 HBuilderX 5.26 内置编译器同源），vue 锁 3.4.21
- 产物：`dist/build/app`（24 页面路由 + entryPagePath=首页 + 公网地址注入）
- 分发：GitHub Release；`Apk/` 与 `.hbuilderx/` 不入库
- 测试基线：MuMu 基座全链通过（tabbar/QuickPanel/播放/歌词/连播/横竖屏/公网 API）；Playwright H5 e2e 29/29

## 四、运营约束（产品规则）

- 免登录可播放已发布歌曲；播放接口完全匿名，不做令牌校验
- 歌曲发布四项强制校验：歌名、歌手、时长、歌词缺一不可
- 上传功能仅登录用户；导入/发布仅管理员
- 管理员邀请：邮件 + CDK 双通道，注册码明文仅展示一次
- 需求投票不可撤销；declined/withdrawn 可被管理员重新开启
- 管理员批量导入等重操作建议走局域网地址（公网 Funnel 中转仅承载听歌与轻量请求）
